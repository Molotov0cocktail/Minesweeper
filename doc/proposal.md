# 需求提案 proposal.md

## v1.4.0 手柄与防猜测生成（2026-10-31）

用户要求增加手柄操作、改进重排防猜测，并更新本地已安装程序。延用经典视觉、存储键和安装目录。

- FR16 标准Gamepad：十字键/左摇杆移动，南键A/叉翻开或确认，西键X/方块标记，东键B/圆取消昵称，Start暂停/继续，长按北键Y/三角800ms重开。连接状态和映射提示中文显示；非standard映射仅提示、不猜测布局。死区0.35，方向初次立即移动、300ms后每100ms重复；动作键仅边沿触发。连接/重新启用需先松开所有操作，失焦/输入框不误触，断开停止输入。
- FR17 求解修复：子集关系双方向检查；邻居表在单次推理中复用；非法布局/首点安全返回不可解。高级重排的移雷验证使用与当前mineSet匹配的基准推导状态，预算准确封顶。
- FR18 首点防猜测在独立module Worker生成；显示“正在生成无猜棋盘…”，计时从生成结束翻格后开始；生成期间禁止翻格/标记，可重开或换模式取消；旧结果不能污染新局。8秒超时或Worker异常回退普通安全开局并明确提示，不在UI线程补跑重排。切到后台生成完成后暂停。
- FR19 发布1.4.0并在原InstallLocation就地安装更新；保留外来文件、排行榜与设置，验证运行副本版本与新功能。没有实体手柄时须说明仅模拟Gamepad验收，不宣称硬件实测。
- 参考：[W3C标准手柄布局](https://www.w3.org/TR/gamepad/#remapping)。完整组合解算器、自定义手柄重映射与震动不在本轮范围。


## v1.3.0 质量与体验升级（2026-10-31）

用户授权自主查找问题并优化。范围限定为可验证的玩法修复与交互升级，延续经典风格及现有安装形态。

- FR12 健壮性：非法坐标（含小数、NaN、字符串）安全返回；首点旗/问号不布雷、不启动计时；损坏的榜单条目不会导致页面崩溃，返回成绩不可改写内部数据。
- FR13 交互：键盘方向键移动、Enter/空格翻开或 chord、F 标记或镜像 chord；P 暂停/继续，F2 重开。输入框/弹窗中不触发游戏快捷键。切出窗口自动暂停，返回需手动继续。
- FR14 界面：显示当前难度、棋盘规格、对局状态、已开安全格进度及操作提示；难度选中态、折叠菜单语义、暂停按钮状态准确；昵称弹窗聚焦、Enter 提交、Escape 关闭及 Tab 焦点限制。
- FR15 显示与性能：模式切换立即适配；小窗口保留可滚动棋盘；高分屏按 DPR 绘制；仅在棋盘变化时重绘，计时器只更新文本；暂停重开清除遮罩与待提交成绩。
- 验收：新增回归测试先红后绿、全量测试、具有失败退出码的真实 Electron 交互冒烟、独立安装器重打包、E2E、提交推送及 v1.3.0 Release。
- 延后：完整求解器、异步 Worker 生成、存档、主题系统、运行时依赖大版本升级；高级防猜测首点仍可能耗时。

## 1. 目标与非目标

### 目标
构建一个运行在 **Electron** 上的扫雷桌面程序（Minesweeper），具备：
- 自定义棋盘（行列、雷数）与三种标准扫雷模式
- 拖动缩放显示、窗口缩放自适应
- 经典交互：左键扫雷 / 右键循环标记（旗→问号→无）/ 已打开格子的双击式推理
- 防猜测模式（自动重排保证可解，超限自动关闭并提醒）
- 正向累加计时器、暂停遮盖、三种标准模式的排行榜（区分防猜测开/关）
- 中文界面文案、经典扫雷视觉风格

### 非目标
- 不做在线对战、不做多用户、不做云同步
- 不接入后端服务器，排行榜仅存本机
- 不实现"用户自定义皮肤"等可扩展功能
- 不保证数学意义上 NP 完全的"绝对可解"（见 detailed-design 的求解器说明）

## 2. 目标用户 / 运行环境
- 普通扫雷玩家，Windows 11（开发与打包目标平台为 win32/x64）
- 通过 `npm start` 开发运行；通过 electron-builder 打包生成**独立便携安装器** `MinesweeperSetup-1.2.0-win.exe`（内含游戏文件，双击安装/卸载）

## 3. 输入 / 输出 / 外部依赖
- **输入**：鼠标（左键/右键）、键盘（可选：R 重开、P 暂停）、行列/雷数数值输入、昵称输入
- **输出**：Canvas 棋盘渲染、DOM 控件、排行榜展示、弹窗提醒
- **外部依赖**：Electron（含内置 Node.js）、Canvas 2D API、localStorage；
  开发期依赖 Vitest（测试）、electron-builder（打包）

## 4. 功能需求（FR）

### FR1 棋盘与模式
- FR1.1 三种标准模式按钮：初级 9×9 / 10 雷，中级 16×16 / 40 雷，高级 16×30 / 99 雷
- FR1.2 自定义模式：通过输入框设置行数、列数、雷数；应用后生成对应棋盘
  - 自定义参数合法性约束（见 FR1.4）
- FR1.3 自定义模式对局**不记入**排行榜
- FR1.4 参数约束：
  - 行、列范围 5~60（含）
  - 雷数 ≥ 1 且 ≤ `min(⌊总格子数 × 0.8⌋, 总格子数 − 9)`（保证至少可容纳首点 3×3 安全区，避免空局/过密导致不可生成）

### FR2 尺寸与缩放
- FR2.1 拖动棋盘右下角/边缘的**缩放手柄**可连续调整格子像素大小（缩放显示），
  行列数与雷数不变；格子大小限定在 [16, 48] px
- FR2.2 窗口尺寸变化时棋盘自动等比缩放适配窗口（保持宽高比），格子大小同样落在 [16, 48] 内

### FR3 鼠标交互（核心规则）
- FR3.1 左键点击未打开格子：翻开（扫雷）
  - 首次点击必安全，且自动递归翻开周围 0 区（空区扩散）
- FR3.2 右键点击未打开格子：三段循环标记 旗→问号→无
  - 旗=标记雷，问号=存疑，无=清除
- FR3.3 左键点击已打开的数字格：**chord**。
  若该格数字 == 周围已标旗数，则翻开周围所有未标旗的格子；
  若其中任何一格为雷 → 触发踩雷失败
- FR3.4 右键点击已打开的数字格：**镜像 chord**。
  若该格数字 == 周围未翻开格子数，则把周围所有未翻开格子全部标旗
- FR3.5 旗数上限 = 总雷数；超过时忽略该次标旗（防止标旗数大于雷数）

### FR4 计时器与暂停
- FR4.1 计时器为**正向累加**计时（从 0 开始，非倒计时），首次翻开后开始
- FR4.2 暂停按钮：点击后暂停计时并**遮盖屏幕**（遮罩挡住棋盘）；再次点击继续
- FR4.3 胜利/失败时计时停止

### FR5 胜负与重开
- FR5.1 翻开全部非雷格即胜利；踩雷即失败
- FR5.2 重开按钮：按当前模式（行列/雷数/防猜测开关）重新开局并重置计时

### FR6 防猜测模式
- FR6.1 开关（默认开）。开启后，首次点击并布雷后，检测整局是否可在无猜测前提下被逻辑推导解开
- FR6.2 若检测到"必须靠猜测"：**重新生成整局雷布局**（保持行列、雷数、首点安全），重新检测；最多重试 **最大重置轮数**（可配置，默认 20）
- FR6.3 关闭条件（满足其一）：
  - 雷密度 > **50%**（雷数 / 总格子数），直接关闭并提醒，不再尝试
  - 重排达到最大重置轮数仍不可解：保留最后一次布局（首点安全），关闭该局防猜测并提醒用户
- FR6.4 关闭或超限时：界面弹窗/横幅提醒用户"防猜测已关闭（原因）"
- FR6.5 排行榜必须区分"防猜测开"与"防猜测关"两套榜单
- FR6.6 防猜测**实现方式**可配置（侧栏）：**标准（整盘重排，默认，即 FR6.2 行为）** 与 **高级（局部重排，见 FR11）**；最大重置轮数可调（范围 1~200）
- FR6.7 防猜测相关设置持久化到 localStorage（key 见 detailed-design），跨启动保留

### FR7 排行榜
- FR7.1 仅三种标准模式生成榜单；每模式分"防猜测开 / 关"两个榜单，共 6 组
- FR7.2 每组榜单取前 10 名，按用时升序（快者居前），记录：昵称、用时(ms)、完成日期
- FR7.3 胜利后弹出昵称输入（默认记忆上次昵称）；若成绩进入该组前 10 则写入 localStorage
- FR7.4 数据存 localStorage（key 见 detailed-design），跨启动持久

### FR8 界面文案与风格
- FR8.1 全部界面文案中文
- FR8.2 视觉风格：经典 Windows 扫雷 3D 浮雕风（灰色底、立体格子、经典数字配色）
- FR8.3 **界面美化**：在保持经典风基调（灰色浮雕、经典数字配色）的前提下升级视觉
  （阴影、过渡动画、hover/active/focus 态、强调按钮、面板层次），不得引入外部资源
  （受 CSP 约束：系统字体栈 + 纯 CSS）

### FR9 左侧侧栏与页面布局
- FR9.1 页面左侧提供**侧栏**（宽 240px，默认收起）：等级选择（初级/中级/高级）、
  自定义行列/雷数、防猜测设置区、排行榜入口（v3 起**不再有**安装/卸载入口）
- FR9.2 顶栏保留：左上角**汉堡按钮**（三条横线，点击展开/收起侧栏）、标题、
  剩余雷数、计时、暂停/重开按钮；防猜测关闭横幅保留
- FR9.3 排行榜入口在侧栏；点击后在**主页展示**排名面板（6 组标签页：
  3 模式 × 防猜测开/关），不再全屏弹窗遮罩
- FR9.4 侧栏展开/收起时棋盘自动缩放适配（可用宽度扣除侧栏宽度）
- FR9.5 侧栏展开时覆盖或挤压按 FR9.4 处理；窄窗口（最小 480×360）下允许棋盘溢出（经典程序行为）

### FR10 独立安装器 MinesweeperSetup（v3，替代 v2 应用内安装/卸载管理器）
- FR10.1 **分发形态**：dist 仅产出单个便携 exe `MinesweeperSetup-1.2.0-win.exe`
  （electron-builder `portable` target，NSIS 压缩，内含游戏文件）。**游戏程序本体不再内置
  任何安装/卸载功能**（无入口、无向导、无 IPC），游戏被彻底剥离
- FR10.2 **setup 双击语义**（唯一管理入口）：
  - 未安装 → 安装向导：欢迎 → 选择安装地址（默认 `D:\Minesweeper`，无 D 盘回退其他
    非系统盘，兜底 `%USERPROFILE%\Minesweeper`，始终可手动修改）→ 快捷方式选项
    （桌面/开始菜单，默认勾选）→ 进度 → 报告
  - 已安装 → 卸载确认界面（显示安装目录/版本，点击卸载 → 清单式卸载 → 报告）
  - 命令行：`--uninstall` 静默卸载（控制面板 UninstallString 入口）；
    `--install-dir <dir>` 静默安装（自动化/E2E）；`--no-desktop-shortcut` /
    `--no-startmenu-shortcut` 关闭对应快捷方式
- FR10.3 **安装动作**：复制自身完整运行时到目标目录（**排除** setup 自身的 app.asar 与
  内嵌游戏目录 `resources/game-app/`；setup exe **重命名为 Minesweeper.exe**）+
  内嵌游戏文件映射复制为目标 `resources/app/`（Electron unpacked 应用目录，安装副本
  可独立运行）→ 写 `install-manifest.json`（相对路径清单，记录**安装后**路径）→
  注册表卸载项（`UninstallString = "<setup exe>" --uninstall`、`InstallLocation`=目标目录、
  DisplayIcon=安装副本 exe）→ 快捷方式指向安装副本 exe
- FR10.4 **卸载**：清单式删除——重定位链（自身目录 → 注册表 `InstallLocation` →
  `UninstallString` 目录 → 无）→ 只删清单内文件/自建目录；清单外内容跳过并提示；
  删除失败（占用/权限/不存在）分类报中文原因继续；结束汇总报告 → 清理注册表/快捷方式
  → 占用文件延迟 .bat 清理
- FR10.5 **setup 零痕迹**：自身不写注册表、AppData、快捷方式；userData 与日志全部落在
  %TEMP%（便携解压目录退出自动删除）；**删除磁盘 exe 即无任何印记**
- FR10.6 **移动目录自愈**：游戏启动时（仅打包形态）检测注册表 `InstallLocation` 与自身
  目录不符且自身目录存在清单 → 自动更新 `InstallLocation`（保持"移动安装目录后 setup
  仍能定位卸载"的 v2 能力）
- FR10.7 旧版残留检测（旧 NSIS 目录/快捷方式/注册表）保留在 setup：检测 + 一键清理
- FR10.8 游戏程序剥离后日志仍写入 `%LOCALAPPDATA%\Minesweeper\logs\`（按日轮转，
  清理 7 天前）；主进程未捕获异常写日志不闪退

### FR11 高级防猜测模式（局部重排）
- FR11.1 侧栏可切换实现方式：**标准（整盘重排，默认）** / **高级（局部重排）**；
  可设置最大重置轮数（默认 20，范围 1~200，标准模式使用）与
  高级模式区域重排次数（默认 20，范围 1~200）
- FR11.2 高级模式算法（用户需求语义）：
  1. 首次点击布雷后模拟推导；若出现需猜测的情况，取**最小的歧义连通簇**（8 邻接）为小区域
  2. 保持小区域外雷不动，仅重排小区域内的雷（区域雷数不变）；重排一定次数（FR11.1 可设）
    仍不可解 → 进入 3
  3. **小区域减少 1 颗雷**，移至正常区域：候选位置逐个尝试，若该位置导致正常区域
    出现新猜测则换位；找到不引起正常区域猜测的位置后继续区域重排
  4. 重排后仍出现猜测 → 重复步骤 2~3（区域雷数继续递减）；区域雷数为 0 或
    无可用候选位置或超过内部预算 → 高级模式失败
- FR11.3 高级模式失败 → **回退标准整盘重排**（按 FR6.2）；标准也失败 → 现有关闭+横幅逻辑
- FR11.4 高级模式与标准模式一样受密度 >50% 短路约束；结果保证：雷数不变、
  首点 3×3 无雷、ok 时必可无猜解

## 5. 约束与假设
- 单窗口应用，无多窗口
- 核心逻辑（棋盘/求解/游戏/排行榜）必须是**纯 JS 模块**，不依赖 DOM，
  以便 Vitest 在 Node 环境严格单测；渲染层薄
- 排行榜按标准模式与防猜测开关隔离；自定义模式不计榜
- git 自动推送：每次任务/改动完成即 commit + push；若 push 因认证失败则暂停询问用户

## 6. 成功标准 / 验收检查
- 全部 Vitest 测试通过（board / solve / game / leaderboard / renderer-ui / installer / setup-ui）
- `npm start` 可启动 Electron 窗口并完整可玩
- 手动验收清单：
  1. 三种标准模式切换后棋盘尺寸正确
  2. 自定义行列/雷数生效且非法输入被拦截
  3. 拖动手柄可缩放、窗口缩放自适应
  4. 左键/右键/chord/镜像 chord 行为符合 FR3
  5. 防猜测开启时：对可解局面无猜测；对高密度/20 次失败场景正确关闭并提醒
  6. 计时、暂停遮盖、重开行为正确
  7. 胜利输入昵称后上榜，刷新 localStorage 后仍在
  8. `npm run dist` 产出 `dist/MinesweeperSetup-1.2.0-win.exe`（dist 内仅此一个产物）；
     双击该 exe 可安装/卸载；已安装游戏无任何安装相关 UI/IPC；
     移动安装目录后运行游戏，再双击 setup 仍可卸载；删除 setup exe 后无残留印记
- README.md 完整描述运行/测试/打包/功能/操作说明

## 7. 已确认决策记录（来自用户）
| 决策项 | 结论 |
|---|---|
| 技术栈 | Electron |
| 拖动改尺寸含义 | 拖动仅缩放显示（改格子像素大小） |
| 防猜测调整方式 | 重排整局雷布局（首点安全） |
| 防猜测关闭阈值 | 密度>50% 或重排 20 次仍不可解 |
| 首点安全 | 必安全 + 空区扩散 |
| 右键标记 | 旗→问号→无 循环 |
| 附加元素 | 重开/剩余雷数/中文/正向计时/暂停遮盖/排行榜/昵称 |
| 榜单存储 | localStorage |
| 打包 | electron-builder 打包 exe |
| 自定义是否入榜 | 否 |
| 界面风格 | 经典扫雷风格 |
| git 推送 | 自动推送，认证失败暂停询问 |
